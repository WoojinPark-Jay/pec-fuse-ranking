# PEC-Fuse interactive tutorial

This directory contains the English project page, browser-only interactive tutorial, and live ranking demo for PEC-Fuse. Korean presentation is currently disabled.

```bash
pnpm install
pnpm dev
```

The production build is static and is published to the repository's GitHub Pages site.

```bash
pnpm build
```

Worked user, query, candidate, and feature examples are synthetic. Results sections separately display released aggregate experimental results; those are not generated by the interactive examples. The tutorial does not load private operational rows, fitted private models, or credentials.

The public navigation does not offer a manuscript download or a provisional paper citation. Software references should identify the repository URL and commit; final publication metadata can be added later.
