04 · 수식: 평균과 attention의 차이

Private의 C_mean은 시간감쇠 가중 이력 벡터를 정규화한 방향과 후보의 cosine입니다. 개별 cosine을 단순 평균한 public C_mean과 다릅니다.

Private: ρⱼ = exp(−ageⱼ / 30일)
C_mean = cos(candidate, Σⱼ ρⱼ historyⱼ)
αⱼ ∝ exp(cos(candidate, historyⱼ) / 0.18) × ρⱼ
C_attn = Σⱼ αⱼ cos(candidate, historyⱼ)

max는 가장 닮은 과거 기사 하나, top-3는 가장 닮은 최대 세 기사의 평균을 남깁니다. Attention은 후보와 닮고 더 최근인 기사에 더 큰 가중치를 둡니다. 후보가 바뀌면 attention 가중치도 달라집니다.

압축하면 사라지는 구분

(P,C)=(0.8,0.2)와 (0.2,0.8)은 단순 평균하면 둘 다 0.5입니다. 별도 좌표로 남기면 “프로필 지지”와 “클릭 이력 지지”를 scorer가 구분할 수 있습니다. 이 예시는 정보 구분을 설명하며, 모든 데이터에서 성능 향상을 보장하는 증명은 아닙니다.

07 · public P와 C가 같은 이력에서 나오는 이유

단위 후보 벡터 v와 단위 이력 벡터들의 평균 h̄를 생각해 봅시다.

p = vᵀh̄ / ‖h̄‖₂
C_mean = meanⱼ(vᵀhⱼ) = vᵀh̄
따라서 C_mean = ‖h̄‖₂ × p

같은 순위, 다른 크기: public p와 C_mean

후보 A/B/C의 p를 0.8 / 0.5 / 0.2로 고정하고, 이력 평균 벡터의 노름을 바꿔보세요.

단위 이력 벡터와 단위 후보 벡터를 가정한 수학 예시입니다. r=0에서는 정규화된 p의 식이 정의되지 않으므로 이 데모에서 제외합니다. 빈 이력 처리는 실제 구현 규약을 따릅니다.

한 query에서는 ‖h̄‖₂가 모든 후보에 공통인 양수이므로 두 필드의 후보 순서는 같습니다. 서로 다른 query에서는 이 배율이 달라질 수 있습니다. 따라서 숫자는 항상 같지 않지만 독립적인 두 semantic evidence source도 아닙니다.

여기서 public C attention은 cosine 기반 요약입니다. Private의 날짜 감쇠 요약을 public 정의에 그대로 대입하지 마세요.

09 · 점수에서 순위와 지표로

모델은 각 후보 행에 score를 매기고, 같은 query 안에서 내림차순 정렬합니다. Private headline의 ExtraTrees class-1 probability는 ranking score로 사용하며 calibrated CTR이라고 해석하지 않습니다.

같은 기사라도 순서를 바꾸면 지표가 달라집니다

양성 기사 A·C와 음성 기사 B·D·E를 가정합니다. 순위의 label을 직접 입력하세요.

이 데모는 한 query의 NDCG@k·Recall@k·reciprocal rank를 계산합니다. 논문의 NDCG@10 결과가 아니며, MRR은 여러 query의 reciprocal rank 평균입니다.

DCG@k = Σᵣ₌₁ᵏ labelᵣ / log₂(r+1)
NDCG@k = DCG@k / IDCG@k
Recall@k = top-k 양성 수 / 전체 양성 수
Reciprocal rank = 1 / 첫 양성 순위

한 사용자가 여러 query를 가질 수 있으므로 불확실성은 행을 독립적으로 뽑는 것이 아니라 user 단위로 묶어 평가합니다. Paired 비교는 두 모델에 같은 후보 행을 사용합니다.
