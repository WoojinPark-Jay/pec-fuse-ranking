# Preserved WSDM v101 Materials

This directory preserves the earlier short-paper artifact records for provenance and historical comparison. They are not the active result bundle for the IEEE Access manuscript.

Current visitors should begin with the repository root `README.md` and use `results/access/`, `docs/ACCESS_ALIGNMENT.md`, and `docs/ACCESS_RESULT_FILES.md`.

The archived file names and internal labels are retained unchanged so that the earlier revision remains auditable.
